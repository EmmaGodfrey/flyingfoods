# React + Tailwind UI Template

Use this component as a drop-in starting point for new pages that must follow the repository design system.

## File

- `docs/ui/component_template.react.tsx`

## Usage

1. Copy the component into your frontend app (for example: `src/components/layout/ERPBlueWhiteTemplate.tsx`).
2. Ensure Tailwind CSS is configured.
3. Install Lucide React: `npm install lucide-react`.
4. Replace static placeholder content with real route/content data.

## Notes

- Palette, spacing, typography, and interaction behavior are aligned with `docs/05_UI_DESIGN_SYSTEM.md`.
- Icon sizing conventions are defined in `docs/ui/ICON_SCALE.md`.
- Keep motion subtle and preserve the current visual hierarchy.
- Avoid adding extra effects unless they remain minimal and professional.
