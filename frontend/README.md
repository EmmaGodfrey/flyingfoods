# Flying Foods ERP Frontend

React/TypeScript interface for the role-based restaurant and inventory
workflows.

Implemented screens include:

- Kitchen and waiter real-time boards
- Stock on hand, issue notes, transfers, and stock-takes
- Procurement budgets, purchase orders, GRNs, and invoice matching
- Wastage and approval queues
- Menu and versioned recipe administration
- Operational reports and administration

## Run

```powershell
npm ci
npm run dev
```

Set `VITE_API_BASE_URL` when the API is not at `http://localhost:8000`.

## Build

```powershell
npm run build
```
